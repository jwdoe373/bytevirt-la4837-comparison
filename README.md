## 一、先把"4837"这个词说透：它不是玄学，是联通的 AS 编号

很多人一听"4837"就觉得是个营销噱头，其实它是个有明确技术含义的东西。AS4837 是中国联通（China Unicom）的一个自治系统编号，对应的网络是联通的 169 骨干网，也就是大家平时家里装联通宽带时实际走的那张网。

**简单说就是：**当一台美国机房的 VPS 在回程路由里经过 AS4837 节点回到国内时，它就被叫做"4837 线路 VPS"。这个"经过"通常发生在回国前一两跳和国外前一两跳，路由里经常能看到 `219.158.*.*` 这种开头的 IP，那就是联通 169 网的标志性地址段。

**为什么大家突然开始追捧 4837？**原因其实挺朴素：便宜，而且够用。

- CN2 GIA 是电信的精品网，稳定性最好，但价格也最贵，动辄 $6000/Gbps 的成本，落到用户头上就是月付十几刀起步
- AS9929（CUII）是联通的 A 网，定位高端，负载低、延迟稳，但同样不便宜
- AS4837 是联通的普通民用网，因为用的人多、负载相对可控，加上 2021 年下半年海缆扩容之后国际出口带宽改善了不少，实际体验反而比想象中好

**大致的线路质量排名是这样的：CN2 GIA ≈ AS9929 > AS4837 > 普通 BGP。**4837 卡在中间——比上不足，比下有余。它的核心优势是"三网通吃"：电信、联通、移动回程都能走 4837，不像某些线路只对联通友好。再加上价格只有 CN2 GIA 的几分之一，对预算有限又想要稳定回程的人来说，确实是个折中方案。

当然，4837 也有它的短板。晚高峰时段，特别是电信用户回程走 4837 时，偶尔会有丢包和延迟波动，这是民用网的通病。如果你是电信重度用户、对延迟极其敏感（比如做高频交易、实时游戏服务器），那 4837 可能不是最优解，CN2 GIA 或 9929 会更合适。但如果你是建站、跑爬虫、做转发、挂机器人、跨境小店这类对延迟容忍度在 50-200ms 的场景，4837 的性价比就非常能打了。
